# نظام المعرفة القابلة لإعادة الاستخدام

يحافظ كل مشروع تعريب على مسارين منفصلين:

1. `PROJECT_DISCOVERIES.md`: معرفة عامة اكتشفها المشروع وتصلح لألعاب ومحركات متعددة.
2. `../engines/<engine-id>.md`: معرفة خاصة بمحرك أو عائلة صيغ بعينها.

عند مراجعة المشروع، تُدمج العناصر العامة المقبولة في `GENERAL_LOCALIZATION_KNOWLEDGE.md` بالقالب الأساسي، ويُنقل ملف المحرك المقبول إلى مكتبة `engines/`. ملف المقترحات وحده لا يكفي؛ المطلوب دليل قابل للتنفيذ يتضمن الأدوات والنسخ والأوامر والتجارب والفشل والحلول واختبار القبول.
