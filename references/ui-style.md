# أسلوب الواجهة والقوائم

- الأزرار وعناصر القوائم بصيغة المصدر أو الاسم: حفظ، تحميل، رجوع، تطبيق، إلغاء.
- التعليمات بصيغة الأمر: «اضغط F لفتح الباب».
- اختر زوجًا ثابتًا لخيار التفعيل: تشغيل/إيقاف أو مفعّل/معطّل.
- رسائل التأكيد تذكر النتيجة المهمة، ورسائل الخطأ واضحة بلا لوم للاعب.
- حالات الانتظار: «جارٍ التحميل…»، «جارٍ الحفظ…».
- اختر أقصر صياغة طبيعية ولا تختصر الكلمات اعتباطيًا.
- ترجم بحسب وظيفة الشاشة لا بحسب الكلمة المنفردة؛ `Load` و`Continue` ونحوها
  متعددة السياق.
- حافظ على accelerator أو الأيقونة أو زر التحكم إن كان جزءًا من البنية.
- راعِ القياس الفعلي. عند الفيضان: صياغة أقصر، ثم حجم خط بسيط، ثم الحاوية أو
  auto-size. لا تعتمد نسبة أحرف عالمية.
