## خريطة الموارد والمسارات القابلة لإعادة الاستخدام

سجّل الأنماط لا كل الملفات. استخدم `<game_root>` للمسارات داخل اللعبة،
وافصل مسار الأرشيف عن المسار الداخلي. اذكر اللعبة/البناء/المنصة وحالة الدليل
لكل نمط؛ أعد التحقق في لعبة أخرى من المحرك نفسه قبل الاعتماد عليه.

## مودات وحلول التعريب المجتمعية

سجّل فقط المودات التي عالجت حاجة تعريب فعلية (نصوص، خطوط، RTL، واجهة،
صور، ترجمة نصية، أو تحميل حزمة اللغة). فرّق بين «مرشح خارجي» و«مختبر على
اللعبة/البناء الحالي»، ولا تفترض توافق مود لعبة شقيقة مع هذه اللعبة.

| المود/المسار | الحاجة التي يعالجها | اللعبة/الإصدار/المنصة | الرابط والإصدار/الترخيص | التبعيات/التعارض وترتيب التحميل | القرار والدليل | إزالة/استعادة |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

إن عُدّل مود مرخص أو بُني مود مستقل، سجّل سبب الاختيار، مصدر النسخة، حدود
التغيير، اختبار عمل العربية، اختبار عدم المساس باللعب، والقيود التي يجب
إعادة فحصها في لعبة أخرى. لا تنقل شيفرة المود أو أصول اللعبة إلى القالب.
