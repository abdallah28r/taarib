Install guide

From an empty folder to your first localization request in minutes. You need your own copy of the game, Git, Python 3, and Claude Code or Codex.

What you need

  • Your own copy of the game.
  • Git and Python 3 (with the packages: pip install -r requirements.txt).
  • A Claude Code or Codex subscription, or both.

Get the template

Choose a folder for the template, for example one named Arabic Game. Open a terminal inside it and run:

git clone https://github.com/abdallah28r/taarib.git
cd taarib
pip install -r requirements.txt

One folder per game

A folder named taarib appears. Rename it after the game you are localizing, for example Cyberpunk 2077. Each game gets its own copy of the template; keep a clean original for other games.

Open it in your agent

Open the agent you will localize with, then follow its section:

CodexClaude Code

In Codex

  1. Open a new chat and choose “New project”.

  2. Add the folder you renamed (here Cyberpunk 2077, formerly taarib) and name the project, for example “Localize Cyberpunk 2077”.

  3. Check that the folder is the one you added, then press “Create project”.

  4. Open a new chat inside the project and type your localization request.

In Claude Code

  1. Open a new chat in Claude Code, press “Choose…” and pick the folder you renamed (here Cyberpunk 2077).

Screenshots for the remaining Claude Code steps are coming soon.

Ask for the localization

Type «عرّب اللعبة» (localize the game). The agent asks one set of questions at the start: the game's name and location, whether images are in scope, whether it may launch the game, and how its subagents should work. Then it works on its own.

What happens next

  • It asks you once to check a pilot: the main menu and first scene in Arabic, in your game.
  • And once more at the end, to play the full localization and accept it.
  • In between, follow everything from the follow-up pages in the game's folder.
