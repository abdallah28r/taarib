لماذا تعريب؟

خطوات تعريب لعبة كاملة، مع فحوص يشغّلها الكود.

وكيلك يعمل، وأنت تتابع

لوحة تقدم ولوحة مهام تتحدثان وحدهما: ما أنجزه الوكيل، وما يعمل عليه، وما ينتظر جوابك.

عربي سليم داخل اللعبة

تشكيل الحروف وترتيبها من اليمين لليسار، وتقسيم الأسطر بعرض صندوق اللعبة الحقيقي.

تغييرات يمكن الرجوع عنها

نسخة احتياطية قبل أي تعديل، وتثبيت قابل للإزالة، وتجربة أولى تراها بعينك قبل الترجمة الكاملة.

مترجم ومدقق منفصلان

كل جملة تُدقق قبل أن تدخل اللعبة، مع مسرد للمصطلحات وأصوات الشخصيات.

الصور أيضًا

تعريب النص داخل الصور، مع كل نسخة جُرّبت وسبب قبولها أو رفضها، وإخفاء ما يحرق الأحداث.

بوابات لا تُتجاوز

لا تنتقل المرحلة إلا حين يتحقق الكود من الملفات نفسها، لا من كلام الوكيل.

يعمل مع Claude Code و Codex

اختر أحدهما، أو اجعلهما يعملان معًا على المشروع نفسه.

Claude Code

وكلاء فرعيون للمترجم والمدقق والباحث ومعرّب الصور، وحراس يمنعون الكتابة في اللعبة قبل النسخ الاحتياطي.

Codex

القواعد نفسها في AGENTS.md، وتعريب الصور عبر أداة الصور المدمجة في Codex.

لوحة التعريب

المرحلة وشروطها، والتقدم، وما ينتظرك.

لوحة المهام

ما ينوي الوكيل فعله، وما يعمل عليه، وما أنجزه بدليل.

النصوص قبل وبعد

كل جملة بجانب أصلها، مع بحث وملاحظات المدقق.

الصور قبل وبعد

كل صورة بنسخها المجرّبة، وما يحرق الأحداث مخفي.
