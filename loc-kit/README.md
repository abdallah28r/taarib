# Localization kit

Copy these templates into a project after discovery. Keep engine-specific
knowledge separate from reusable project discoveries. Every claim records
status: verified-project, documented-external, candidate, or rejected,
source, date, version and reproduction notes.

Suggested files: GAME_CONTEXT.md, CHARACTERS.yaml, SYSTEMS.md,
and ENGINE_NOTES.md. Per-string context lives in each unit's `context` field.
