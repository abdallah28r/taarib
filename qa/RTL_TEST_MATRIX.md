# RTL and Arabic test matrix

Test real builds and pseudo-localized builds separately. Cover UI, dialogue,
subtitles, images, names, numbers, dates, URLs, variables, punctuation,
mixed Arabic/Latin, save/load, controller input, truncation, font fallback,
and every supported resolution/device. Record build, scene, trigger,
expected result, actual result, screenshot/video, severity, owner, fix and
retest result. Pseudo-RTL is a layout stress test, not proof of Arabic shaping.
