وحدات الترجمة: سجل واحد لكل نص ولكل منطقة نص داخل صورة، بصيغة JSONL (سطر JSON لكل وحدة).
يملؤه الآجنت أثناء الاستخراج، ثم يحدّث حالة كل وحدة: مستخرج ← مترجم ← مدقق لغويًا ← مدمج في اللعبة ← مختبر داخل اللعبة.
نسب التقدم تُحسب من هذه الملفات فقط: python scripts/loc.py progress --format chat|md|html
البحث في النصوص ونصوص الصور: python scripts/loc.py search "كلمة"
التفاصيل الكاملة في references/translation-units.md.
