# Contributing

Contributions must preserve the one-writer-per-file rule, protected tokens,
native format structure, and the legal policy. Add a regression test for every
bug fix. Run `python scripts/verify_template.py` before submitting a change.

By contributing you confirm that you have the right to submit your work and that it
is released under this repository's licenses.

Do not submit extracted copyrighted game assets, encryption keys, or proprietary
application code.
