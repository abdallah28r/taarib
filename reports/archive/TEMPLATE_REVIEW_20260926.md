# مراجعة القالب وتنفيذ الإصلاحات — 2026-09-26

## نتيجة التنفيذ

نجح `python scripts/verify_template.py` بعد الإصلاحات في:

- 18 اختبار وحدة.
- compileall للسكربتات والاختبارات.
- سياسة الوكلاء.
- license guard.
- مدقق ملفات المحركات.

## الإصلاحات المنفذة

- التحقق من `patch_sha256` قبل تثبيت أي ملف.
- نسخ احتياطية تحفظ المسار النسبي مع rollback عند الفشل.
- منع نسخ جذر اللعبة أو مجلد backups داخل نفسه.
- حماية المتغيرات والوسوم في pseudo-localization.
- تقليل رفض الاختصارات والعناوين الظاهرة في capture filter.
- إصلاح عدّ الرموز المتكررة في QA.
- إضافة حدود توكن للدفعات في PROJECT.yaml.
- إضافة قواعد مصطلحات حسب السياق.
- إضافة ملف Godot وتوحيد بوابة ملفات المحركات.
- إضافة LICENSE وSECURITY.md وCONTRIBUTING.md وCHANGELOG.md.
- إضافة verify_template.py وسجل امتثال الإصدار.
- إضافة QA أصلي لـ PO/XLIFF ورسائل ICU مع تنبيه فروع الجمع العربية.
- إضافة اختبار تشكيل HarfBuzz للخطوط.
- إضافة مولد CycloneDX SBOM وحزمة نشر تستبعد السجلات الخاصة.
- إضافة constraints مثبتة بتاريخ المراجعة واختبارات regression جديدة.

## ما يزال يحتاج قرارًا أو توسعة لاحقة

- توسيع فاحص PO/XLIFF/ICU ليغطي جميع لهجات الصيغ الخاصة بالمحركات.
- اختبارات HarfBuzz بصرية داخل كل محرك؛ smoke test العام لا يثبت مسار العرض.
- توليد SBOM ثنائي بعد بناء تطبيق تنفيذي فعلي، إن أضيف مستقبلًا.
- تثبيت أدوات catalog الخارجية بإصدارات وبصمات عند اختيارها للمشروع؛ لا تثبت كلها افتراضيًا.
- إضافة fixtures كاملة وround-trip لكل محرك، لا ملفات معرفة فقط.
- فصل سجل الأبحاث الخاص عن حزمة النشر العامة.
