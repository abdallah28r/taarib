# خيارات مستقبلية مشروطة

هذه ليست متطلبات افتراضية. تُضاف فقط عندما يحل الخيار مشكلة فعلية في مشروع محدد.

| الخيار | يفيد عندما | لماذا ليس افتراضيا |
|---|---|---|
| Weblate/Crowdin/Phrase/Lokalise/memoQ | فريق مترجمين، حالات مراجعة، صور سياق، ذاكرة مشتركة | إعداد وحسابات وخصوصية وكلفة محتملة |
| OCR للقطات الشاشة | النصوص مرسومة كصور ولا توجد خريطة أصول موثوقة | OCR العربي يخطئ ويحتاج مراجعة وربط يدوي |
| مقارنة صور آلية | يوجد تشغيل/التقاط قابل للتكرار لنفس الشاشات | تتطلب harness خاصا بكل لعبة وحدودا للفروق المتحركة |
| CI/GitHub Actions | المشروع في مستودع ويمكن تشغيل الفحوص دون ملفات لعبة محمية | لا يجوز رفع أصول اللعبة أو الأسرار، وقد تكون الأحجام كبيرة |
| قاعدة ذاكرة SQLite أو TMS | مشاريع كثيرة ومصطلحات مشتركة وحالات اعتماد | TMX البسيط يكفي غالبا للمشاريع الفردية |
| تدقيق إملائي عربي آلي | توجد أداة مناسبة للنبرة والأسماء الخاصة | كثرة الإنذارات الكاذبة في أسماء الخيال والنقحرة |
| نموذج ترجمة خارجي/API | توجد موافقة وميزانية وسياسة خصوصية واضحة | إرسال نصوص اللعبة لخدمة خارجية ليس افتراضا آمنا |
| Evals لمهارات التعريب | تتكرر المشاريع ويراد قياس التحسن بين إصدارات المهارة | إعداد بيانات ذهبية وصيانة التقييم لهما كلفة |

## مهارات Codex الرسمية التي راجعتها

القائمة الرسمية المنسقة لا تحتوي حاليا مهارة متخصصة بتعريب الألعاب؛ لذلك المهارات المحلية في هذا القالب هي الطبقة الأساسية. الخيارات الرسمية الأقرب تُثبت عند ظهور حاجتها فقط:

| المهارة | الاستخدام المحتمل في التعريب | القرار الافتراضي |
|---|---|---|
| `screenshot` | التقاط شاشة اللعبة كدليل LQA عندما لا توجد أداة التقاط خاصة | لا تثبت حتى نحتاج التقاط سطح المكتب |
| `transcribe` | استخراج الحوار من صوت/فيديو عند غياب نص المصدر | مشروطة بمفتاح API ومراجعة بشرية؛ ليست بديلا عن ملفات اللعبة |
| `speech` | اختبار نطق عربي أو إنشاء صوت مؤقت لأعمال تسمح بذلك | مشروطة بمفتاح API وحقوق الصوت؛ لا تستخدم لتعديل أصوات اللعبة تلقائيا |
| `playwright` / `playwright-interactive` | QA لأداة تعريب مبنية للويب أو Electron | لا تفيد لعبة Windows أصلية مباشرة |
| `jupyter-notebook` | تجارب إحصائية أو مقارنة نماذج/برومبتات كبيرة | السكربتات والتقارير أبسط للمسار اليومي |
| `gh-fix-ci` / `gh-address-comments` | صيانة CI ومراجعات PR إذا أصبح القالب مستودع GitHub | تثبت فقط بعد اعتماد GitHub وCI |

لم تُثبّت هذه المهارات عالميا في هذه الجولة كي يبقى القالب قابلا للنقل ولا يفرض Node أو مفاتيح API أو حسابات خارجية. توجد أيضا مهارتا النظام `skill-creator` و`skill-installer`، وقد استُخدمتا لبناء مهارات القالب والتحقق من قائمة OpenAI الرسمية.
