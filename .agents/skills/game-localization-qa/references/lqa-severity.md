# Suggested LQA severity

- Blocker: crash, corrupted package, game cannot start, progression blocked, or localization cannot be enabled.
- Critical: meaning causes a wrong gameplay action, protected syntax is broken, essential text is unreadable, or large sections are missing.
- Major: wrong meaning, speaker/gender/context failure, severe clipping, disconnected/reversed Arabic, missing glyphs, or inconsistent key terminology.
- Minor: punctuation, spacing, non-blocking awkwardness, small alignment issues, or cosmetic inconsistencies.

Severity describes player impact, not how hard the fix is.
